How do I get a Discord ID? (30 seconds)
  1. In Discord: User Settings → Advanced → Developer Mode → turn it on.
  2. Server ID: right-click your server icon → Copy Server ID.
  3. Role ID: Server Settings → Roles → right-click the role → Copy Role ID.
  4. Paste it here. It's a long number like 123456789012345678.

How do I make a webhook?
  1. In Discord, open the channel → Edit Channel → Integrations → Webhooks → New Webhook.
  2. Click Copy Webhook URL and paste it below.
  3. Press Send test — a message should appear in that channel.
